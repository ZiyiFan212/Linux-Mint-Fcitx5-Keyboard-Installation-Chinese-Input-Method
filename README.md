# Linux-Mint-Fcitx5-Keyboard-Installation-Chinese-Input-Method CN/EN
A reliable solution resolve the issue of system freezing due to the conflict between Fcitx and ibus input method, while installing the simplified Chinese keyboard, this approach adopts Fcitx5 input to avoid any compatible issues, offering a nice Chinese input experience. 

为了解决在下载中文键盘时fcitx和ibus键盘冲突导致系统图形界面冻结的问题，本项目使用fcitx5输入方法作为首选中文键盘，提供一种稳定的解决方案。
